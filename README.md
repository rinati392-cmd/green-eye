# GREEN EYE — סיור גלילה קולנועי

אתר תדמית לפרויקט מגורים, שבו ארבע סצנות וידאו פורקו ל‑**image sequence** ומתנגנות לפי הגלילה:
הגלילה היא "ראש ההשמעה" — קדימה, אחורה, ובקצב של הגולש.

## איך זה עובד

- כל קליף מקור (6.04 שנ׳, 24fps, 1660×1244) פורק ל‑**145 פריימים JPEG** ברוחב 1152px → `docs/frames/s1…s4/`.
- קנבס קבוע במסך מלא מצייר את הפריים שמתאים למיקום הגלילה, עם החלקה (lerp) לתנועה רציפה.
- סצנה 1 נטענת מראש עם מסך פתיחה; סצנות 2–4 נטענות ברקע תוך כדי גלילה.
- אם פריים עדיין לא נטען — מצויר הפריים הטעון הקרוב אליו, כך שאין הבהובים.

## מבנה

```
docs/
├── index.html      hero, קנבס, ניווט סצנות, מסך סיום
├── style.css       עיצוב + פלטת המותג
├── main.js         מנוע ה-scrub, טעינת פריימים, תוכן הסצנות (מערך SCENES)
├── assets/         לוגו (SVG) בגרסה בהירה וכהה
└── frames/s1..s4/  145 פריימים לכל סצנה
```

הטקסטים של הסצנות מרוכזים במערך `SCENES` בראש `docs/main.js`.


## פירוק וידאו מחדש לפריימים

```bash
ffmpeg -i 1.mp4 -vf "scale=1152:-2" -q:v 7 docs/frames/s1/%04d.jpg
```

קבצי הוידאו המקוריים (`1.mp4`–`4.mp4`) אינם נשמרים במאגר — רק הפריימים שנגזרו מהם.

האתר מתפרסם דרך GitHub Pages מתיקיית `docs/` בענף `main`.
